# Changelog

## [0.13.0] - 2026-05-30

### Added
- Fullscreen mode (F11)
- Configurable keyboard shortcuts
- Command execution subsystem
- Terminal output panel
- Command history
- Maximum editor file size protection
- Configurable command allow/deny lists

### Changed
- Project renamed from "Web Norton Commander" to "WebNC"
- Backend renamed from nc_server.py to webnc_server.py
- SSL certificates renamed to webnc_server.crt/key
- Project directory structure reorganized

### Removed
- Babel runtime
- Legacy React prototype files
- Vite prototype files
- Obsolete source tree
